# Shortcut

## Estimate and Gantt views

| Shortcut | Action |
| --- | --- |
| `Ctrl/Cmd+S` | Save current estimate |
| `Ctrl/Cmd+T` | Open a new tab from the default model |
| `Ctrl/Cmd+←` | Activate the previous estimate tab |
| `Ctrl/Cmd+→` | Activate the next estimate tab |

`Ctrl/Cmd` means `Ctrl` on Windows and Linux and `Cmd` on macOS. Tab switching works in both the Estimate and Gantt views.

## Estimate view only

| Shortcut | Action |
| --- | --- |
| `Ctrl/Cmd+W` | Close current tab |
| `Ctrl/Cmd+E` | Toggle between estimate view and client view |

## About

| Shortcut | Action |
| --- | --- |
| `Ctrl/Cmd+W` | Close About |
