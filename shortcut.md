# Shortcut

## Estimate and Gantt views

| Shortcut | Action |
| --- | --- |
| `Ctrl/Cmd+S` | Save current estimate |
| `Ctrl/Cmd+T` | Open a new tab from the default model |
| `Ctrl/Cmd+Z` | Undo the last change in the current tab |
| `Ctrl+Y` | Redo the last undone change |
| `Cmd+Shift+Z` | Redo on macOS |
| `Ctrl/Cmd+←` | Activate the previous estimate tab |
| `Ctrl/Cmd+→` | Activate the next estimate tab |

`Ctrl/Cmd` means `Ctrl` on Windows and Linux and `Cmd` on macOS. `Ctrl+Z` and `Ctrl+Y` are also accepted on macOS. Undo/Redo history is independent for every tab and applies in Estimate, Client, and Gantt views.

## Estimate view only

| Shortcut | Action |
| --- | --- |
| `Ctrl/Cmd+W` | Close current tab |
| `Ctrl/Cmd+E` | Toggle between estimate view and client view |
